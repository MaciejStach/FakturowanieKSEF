# FakturowanieKSEF
Wyciaganie najwazniejszych informacji z faktur KSEF i zapisywanie do pliku Excel

Program automatycznie pobiera faktury z systemu KSEF ze sprecyzowanego folderu i wypisuje je w Excelu w odpowiedniej zakładce
* Data wystawienia / wpisu
* Numer faktury
* Nazwa firmy
* Kwota netto i brutto
* Zawartość faktury
